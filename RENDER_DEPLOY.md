# Genios Aventureros — Despliegue en Render

Este proyecto está preparado para desplegarse como **Static Site** en Render.

## Configuración recomendada
- Tipo: Static Site
- Build Command: dejar vacío
- Publish Directory: `.`
- No necesita un servidor Node/Python para servir el juego.

## Nota
Los navegadores y Render/Linux distinguen mayúsculas y minúsculas en las rutas.
